# 🚂 Поезд чудес — Детская игра

Vue 3-приложение для интерактивного детского праздника, отображаемое на большом телевизоре или мониторе.

## Возможности

- **3 уровня** с уникальными темами и заданиями
- **Drag & Drop** — ведущий перетаскивает кнопки в слоты
- **Цветовое кодирование** — 5 уникальных цветов для идентификации
- **Номера** — дополнительная идентификация на каждом элементе
- **Анимации** — плавные переходы, тряска при ошибке, салют в конце
- **Полноэкранный режим** — оптимизировано для 16:9, 1920×1080 и 4K

## Технологии

- Vue 3 (Composition API, `<script setup>`)
- Vue Router
- Pinia (управление состоянием)
- Vite (сборщик)
- HTML5 Drag & Drop API
- Canvas Confetti (салют)

## Управление игрой

1. Ведущий видит 5 кнопок внизу экрана и 5 слотов вверху
2. Каждый элемент имеет цвет и номер
3. Дети называют цвет и номер нужного слота
4. Ведущий перетаскивает кнопку в соответствующий слот
5. Цвета должны совпадать! При ошибке слот трясётся
6. После заполнения всех 5 слотов → переход на следующий уровень
7. На 3-м уровне после завершения → салют и поздравление!
